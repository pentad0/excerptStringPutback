# excerptStringPutback 仕様書

## 1. 目的

正規表現に一致したテキストを抜粋ファイルへ書き出し、抜粋ファイルだけを編集して、同じ正規表現の位置へ書き戻す。

excerptTextPutback と同じ手順である。

1. 正規表現を指定して、入力ファイルから一致箇所を書き出す。入力ファイルは変更しない。
2. 抜粋ファイルの `edited` だけを編集する。
3. 書き戻すとき、同じ正規表現で入力を再検索する。
4. 見つかった一致が抜粋ファイルの `raw` と順に一致するときだけ、その位置を `edited` で置き換える。

## 2. 用語

| 語 | 意味 |
| --- | --- |
| 入力ファイル | 抜粋元の UTF-8 テキスト |
| 正規表現 | .NET の正規表現。`^` と `$` はファイル全体の端。`.` は改行に一致しない。パターン内の `(?m)` や `(?s)` で変えられる |
| 抜粋ファイル | UTF-8 の TSV |
| raw | 抜粋時点の一致テキスト |
| edited | 書き戻すテキスト |
| start | 抜粋時点の開始位置。0 始まり。単位は C# の `string` と同じ UTF-16 コードユニット |
| length | raw の長さ。通常の日本語は 1 文字が 1 |

UTF-8 の BOM は位置の計算に含めない。

## 3. コマンド

```text
excerptStringPutback excerpt <正規表現> <入力ファイル> <抜粋ファイル>
excerptStringPutback putback <正規表現> <入力ファイル> <抜粋ファイル> <出力ファイル>
excerptStringPutback --help
```

終了コード:

| コード | 意味 |
| --- | --- |
| 0 | 成功。`--help`、`-h`、`help` も 0 |
| 1 | 引数の数が違う、または不明なコマンド |
| 2 | ファイル、正規表現、抜粋ファイル、照合のいずれかに失敗した |

`excerpt` は抜粋ファイルと入力ファイルを同じパスにできない。`putback` は出力ファイルと抜粋ファイルを同じパスにできない。出力と入力が同じパスのときは、読み終えてからそのファイルを置き換える。

空の一致（長さ 0）はエラーにする。正規表現の検索時間は 30 秒を超えると失敗する。

## 4. 抜粋ファイル

UTF-8、改行は LF、BOM は付けない。読み込みでは先頭の UTF-8 BOM、空行、`#` で始まる行を無視する。ただし `# pattern: ` で始まる行は、抜粋に使った正規表現として覚える。書き戻しで渡した正規表現と違う場合は失敗する。

見出し行は次のとおり。

```text
id	start	length	raw	edited
```

データ行はタブ区切りで 5 列。`id` は 1 から欠番なく並ぶ。`length` は `raw` の長さと一致する。

`raw` または `edited` にタブ、改行、二重引用符が含まれるときは、その列を二重引用符で囲み、列内の二重引用符は `""` と書く。それ以外の列は、そのまま書く。

`edited` を空にすると、その一致は削除される。行を削除して一部だけ書き戻すことはできない。残す一致は `edited` を `raw` のままにする。

## 5. 書き戻し

1. 抜粋ファイルを読む。
2. 入力を同じ正規表現で再検索する。
3. 件数、または各 `raw` が現在の一致と違う場合は、1 件も書き戻さず失敗する。
4. 再検索で得た位置へ、後ろの一致から `edited` を差し込む。
5. 一致の外は、元のテキストのまま残る。

`start` は抜粋時点の記録である。書き戻しの位置は、そのときの再検索結果を使う。

## 6. 例

入力 `input.txt`:

```text
名前:太郎
名前:花子
```

正規表現は `名前:\S+`。`excerpt input.txt` の抜粋は次のとおり。

```text
# pattern: 名前:\S+
id	start	length	raw	edited
1	0	5	名前:太郎	名前:太郎
2	6	5	名前:花子	名前:花子
```

1 件目の `edited` を `名前:次郎` にして書き戻すと、結果は次のとおり。

```text
名前:次郎
名前:花子
```

## 7. 対象外

- UTF-8 以外のエンコーディング
- ディレクトリ単位の処理。対象は 1 ファイル
- 長さ 0 の一致
- 入力を分割して読むこと。ファイル全体をメモリに読む
